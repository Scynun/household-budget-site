A complete, offline household budget website for a Vietnamese family (currency VND): dashboard with income, spending, savings rate and a category donut chart; full transaction CRUD with filters and a month picker; per-category monthly budgets with progress bars; bills with due dates and mark-as-paid; savings goals with add-funds; 12-month reports with working CSV/JSON export; and settings with JSON backup import/export and reset. Data persists in localStorage and the whole site runs as plain static files with zero network requests.

## Run it

```
node serve.ts
```

Then open http://localhost:8080 — the dashboard loads with 71 seeded transactions across September–November 2026 for the sample household "Gia đình Minh & Lan".
